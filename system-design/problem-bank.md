## Interview progression
Easy: 1, 7, 9, 13, 17.
Medium: 2, 8, 10, 11, 19, 20, 28.
Hard: 21, 22, 23, 25, 27, 29, 33, 35, 41, 46, 47.

For each problem produce: requirements, assumptions, architecture diagram, component/module boundaries, state table, API contracts, cache strategy, failure matrix, performance plan, security model, accessibility plan, observability and trade-offs.

# Specialized Frontend Systems

## Why it matters
Combine patterns for file upload, dashboards, large forms, collaboration, notifications, command palettes and document editors. Identify when state machines, workers, virtualization, optimistic UI, realtime and persistence interact. Interview drill: choose architecture from constraints. Challenge: design one specialized system in 30 minutes.

## Study contract
Do not memorize a diagram. Explain why each boundary exists, what can fail, how the user experience degrades, how the system is measured, and what changes under a new constraint.

## Interview follow-ups
- 10× traffic/data
- offline or low bandwidth
- partial dependency outage
- strict consistency or concurrent edits
- security/accessibility requirements

## Practical output
Create a one-page architecture, critical data flow, failure matrix and trade-off list.

## How to practise a case study
1. Set a 45-minute timer. Talk out loud, draw on paper or Excalidraw.
2. Do RADIO without reading the solution.
3. Compare with the worked design; list what you missed.
4. Re-do the same prompt 5 days later in 35 minutes.

## Self-review checklist
- [ ] Clarified functional + non-functional requirements and scope
- [ ] Estimated scale where it matters
- [ ] Drew architecture with data flow
- [ ] Defined data model & state ownership
- [ ] Defined API (pagination, errors, real-time events)
- [ ] Covered performance (loading + runtime + perceived)
- [ ] Covered failure modes & offline/stale data
- [ ] Covered a11y, i18n, security
- [ ] Covered observability & testing
- [ ] Stated trade-offs and next steps

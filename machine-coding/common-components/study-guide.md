# Common Component Problems

Modal: open/close, Escape, backdrop policy, focus management, portal, scroll lock and background focus isolation.

Tabs: active tab, keyboard navigation, correct tab/tabpanel semantics, optional lazy mounting.

Accordion: single vs multi-open; store active IDs.

Dropdown: keyboard navigation, outside click, positioning, disabled options, typeahead and portal/z-index.

Toast: queue, timeout, manual dismissal and required focus/hover behavior.

Pagination: page or cursor model, disabled controls and URL synchronization when useful.

Carousel: keyboard, pointer/touch, boundaries, looping and reduced motion.

Date picker: locale, timezone, min/max, keyboard, invalid dates and ranges.

For every reusable component answer: public API? internal state? guaranteed behavior? accessibility contract?

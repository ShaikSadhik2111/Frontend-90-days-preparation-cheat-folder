# Machine Coding

Dedicated frontend interview track for building production-quality features under time constraints.

## Workflow

**Clarify → Model → Component breakdown → State/data flow → Implement core → Loading/error/empty states → Edge cases → Test → Performance/accessibility review → Explain trade-offs**

## Coverage

Requirements, component design, state management, API integration, forms, data display, interaction, accessibility, responsive UI, errors/loading/empty states, performance, testing, concurrency and real-world application components.

## Problem families

- Autocomplete / debounced search
- Data table
- Pagination
- Modal
- Tabs
- Accordion
- Carousel
- File upload
- Kanban board
- Todo application
- Shopping cart
- Multi-step form
- Date picker
- Infinite scroll
- Virtualized list
- Chat UI
- Notification system
- Dashboard

## Time-boxing

Start with a working vertical slice. Then add correctness, edge cases, accessibility, performance and polish in that order. The interview goal is not maximal feature count; it is a coherent, maintainable implementation with deliberate trade-offs.

# 30 — Timed interview simulation

## Format (do one every weekend)
1. Pick a problem you haven't built in the last 7 days.
2. Start a 60-minute timer, record your screen + voice (OBS / Teams / Zoom).
3. Follow the 5-step flow out loud: clarify → plan → happy path → edge cases → wrap-up.
4. At 45 minutes, stop adding features and polish/explain.
5. Watch 10 minutes of the recording: Did you talk? Did you get something on screen in the first 15 minutes? Did you handle loading/error? Keyboard?

## Scoring (1–5)
| Area | 5 looks like |
|---|---|
| Working result | core requirements work, no console errors |
| State design | minimal state, derived values, clear ownership |
| Edge cases | loading/empty/error, race conditions, validation |
| Code quality | readable names, small components, typed props |
| Accessibility | labels, keyboard, ARIA where needed |
| Communication | explains trade-offs, asks clarifying questions |

## Problem rotation (12 weeks)
Autocomplete → Data table → Modal + Tabs → Infinite scroll → Todo with undo/redo → Star rating + OTP → Kanban → File upload with progress → Nested comments → Multi-step form → Toast system → Virtualized list from scratch.

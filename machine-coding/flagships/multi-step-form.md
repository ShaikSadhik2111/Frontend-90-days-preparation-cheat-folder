# Flagship: Multi-Step Form

## Requirements
Steps, validation, back/next, submit and persistence.

## State
currentStep, values, touched/errors, completion, save status.

## Advanced
Dependent fields, async validation, autosave, draft recovery, role-based steps and conflict handling.

## Correctness
Completed values survive navigation; invalid values cannot advance; server remains authoritative.

## Follow-ups
80–500 fields, accessibility, partial saves and network failure.

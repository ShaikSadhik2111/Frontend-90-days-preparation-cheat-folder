# Machine Coding Interview Framework

Opening: “I’ll clarify interactions and edge states, define component/state boundaries, then implement one complete vertical slice.”

Clarify exact user actions, data source, persistence, responsive behavior, accessibility, loading/error/empty, performance constraints, browser support and time.

Classify state as local UI, form, URL, server, shared client or derived.

API checklist: request, response, error, pagination, cancellation, retry and cache.

60-minute strategy:
0–5 requirements
5–10 component/state design
10–40 core implementation
40–50 edge cases/accessibility
50–55 tests
55–60 trade-offs/follow-ups

If behind schedule, finish one complete vertical slice before polishing.

Follow-ups: scale? slow API? out-of-order responses? tests? accessibility? 100k records? caching?

Communicate major decisions while continuing to implement.

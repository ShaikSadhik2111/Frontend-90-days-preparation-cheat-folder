# Machine Coding Checklist

## Before coding
- [ ] Clarify functional and non-functional requirements
- [ ] Define scope and assumptions
- [ ] Identify data/API needs
- [ ] Identify loading, empty and error states
- [ ] Identify edge cases

## Design
- [ ] Component tree
- [ ] State ownership
- [ ] Data flow
- [ ] API contract
- [ ] Reusable boundaries

## Implementation
- [ ] Happy path
- [ ] Validation
- [ ] Loading/error/empty states
- [ ] Accessibility and keyboard behavior
- [ ] Responsive behavior
- [ ] Edge cases and race conditions

## Review
- [ ] Critical behavior tested
- [ ] Performance reviewed
- [ ] Security considered
- [ ] Trade-offs explained
- [ ] Improvements with more time identified

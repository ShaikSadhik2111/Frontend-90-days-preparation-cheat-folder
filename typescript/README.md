## How to study each topic

1. Read the concept.
2. Type every example yourself.
3. Change the example and predict the compiler error before running it.
4. Complete the exercise.
5. Explain the topic aloud in 2–3 minutes.
6. Solve the related interview question without looking at the answer.

## Final TypeScript checklist

Before marking TypeScript complete, you should be able to:

- model objects with interfaces and type aliases
- explain unions vs intersections
- explain inference and narrowing
- use `unknown` safely instead of blindly using `any`
- use `never` for exhaustive checks
- write generic functions and constraints
- use `keyof`, `typeof` and `T[K]`
- use utility types without duplicating models
- write mapped and conditional types
- use `infer`
- explain `as const`, assertions and `satisfies`
- explain structural typing
- configure a strict TypeScript project
- model API DTOs and domain types
- type React props, events, state, refs and generic components
- explain the runtime limitation of TypeScript types

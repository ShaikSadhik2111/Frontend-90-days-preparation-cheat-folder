## Deep dive — Embeddings

Embeddings map content into vectors so semantic similarity can be approximated numerically. Understand dimensions, similarity metrics, normalization, model choice, and the difference between semantic similarity and exact keyword matching. Challenge: embed product descriptions and explain cases where lexical search should complement vector search.

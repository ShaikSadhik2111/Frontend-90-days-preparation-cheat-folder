## Deep dive — Prompting

Prompting is specification design: define task, context, constraints, output contract, examples, and failure behavior. Compare zero-shot, few-shot, role/context instructions, delimiters, and decomposition. Avoid relying on wording tricks for security or correctness; validate important output in code. Challenge: design a prompt that classifies support tickets into a strict schema and test ambiguous inputs.

### Study standard
Explain the concept in your own words, implement the smallest working example, identify at least two production failure modes, and answer one “why this instead of that?” interview question. Then connect the topic to the next stage of the AI pipeline.

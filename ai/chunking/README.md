## Deep dive — Chunking

Chunking determines the units stored and retrieved from documents. Good chunks preserve enough context to answer questions without wasting the context window. Consider headings, paragraphs, tables, code, overlap, metadata, and document structure rather than blindly splitting by character count. Interview drill: design chunking for technical documentation.

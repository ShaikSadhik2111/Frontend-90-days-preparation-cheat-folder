# interview questions

This topic is part of the 90-day frontend interview preparation syllabus.

Detailed notes, examples, exercises, interview questions with direct answers, pitfalls, and revision notes will be added when this topic is studied.


## Deep dive

AI interview preparation should use architecture and trade-offs rather than buzzwords. Be able to explain tokens, context windows, embeddings, chunking, retrieval, reranking, RAG, structured output, function/tool calling, agents, prompt injection, evaluation, latency, cost, and observability. For system design use requirements → data flow → components → failure modes → security → evaluation → scale → trade-offs.

### Study and interview drill
Implement the smallest working example, deliberately introduce one failure, diagnose it, and explain the production trade-off and connection to the next topic.

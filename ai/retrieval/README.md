## Deep dive — Retrieval

Retrieval turns a user query into candidate evidence. Compare lexical, vector, and hybrid retrieval; understand top-k, metadata filters, recall, precision, and latency. Retrieval quality is upstream of generation quality. Challenge: build a retrieval pipeline and inspect false positives and false negatives rather than judging only the final answer.

### Study standard
Explain the concept in your own words, implement the smallest working example, identify at least two production failure modes, and answer one “why this instead of that?” interview question. Then connect the topic to the next stage of the AI pipeline.

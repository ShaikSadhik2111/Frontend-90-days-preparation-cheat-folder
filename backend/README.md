# Backend — TypeScript / Node.js

Backend preparation for a frontend engineer who wants practical full-stack capability and product-company interview readiness.

## Recommended stack

**Primary language:** TypeScript  
**Runtime:** Node.js  
**Fundamentals framework:** Express.js  
**Production architecture framework:** NestJS  
**Optional performance framework:** Fastify  
**Database:** PostgreSQL  
**ORM/query layer:** Prisma or Drizzle  
**Cache:** Redis  
**API style:** REST first; understand GraphQL concepts  
**Validation:** Zod / class-validator depending on framework  
**Testing:** Jest/Vitest + Supertest  
**API documentation:** OpenAPI/Swagger  
**Auth:** JWT + secure cookies/sessions + OAuth concepts  
**Deployment:** Docker + CI/CD

## Learning strategy

Do not treat Node.js, Express and NestJS as competing technologies.

- **Node.js** = server-side JavaScript/TypeScript runtime and platform.
- **Express.js** = minimal HTTP framework; learn it to understand routing, middleware and request/response fundamentals.
- **NestJS** = structured TypeScript framework for modular, maintainable backend applications.
- **Fastify** = optional high-performance HTTP framework and a useful alternative to Express.

Learn Node + HTTP fundamentals first, build APIs with Express, then build a production-style application with NestJS.

## Scope

Runtime fundamentals → HTTP → Express → TypeScript backend patterns → validation → PostgreSQL/SQL → ORM → authentication/authorization → security → caching/Redis → queues/background jobs → file processing → testing → observability → Docker/deployment → API/system design → microservices concepts.

# Mixed Interview Sets — Unknown Pattern Recognition

These problems intentionally do not reveal the expected pattern.

## Required process

`Understand → constraints → brute force → bottleneck → observation → candidate patterns → invariant/state → implementation → dry run → complexity → edge cases → trade-offs`

## Pattern coverage

Each set must mix:

- arrays / strings
- hashing
- two pointers
- sliding window
- prefix/suffix
- stack / monotonic stack
- queue / deque
- linked list
- binary search
- sorting
- heap / Top-K
- intervals
- trees
- trie
- graphs / BFS / DFS
- union-find
- greedy
- recursion / backtracking
- dynamic programming
- bit manipulation

## Rule

Do not start by asking “which LeetCode pattern is this?” Start by asking what repeated work, structure, invariant or constraint the problem exposes.

Each major pattern must have 2–3 complete worked problems elsewhere in the DSA tree; these mixed sets are for recognition and transfer.

# 17 — DevTools and Production Debugging

**Connection:** performance and correctness require evidence.

**Learn:** Elements, Console, Sources, Network, Performance, Memory, Application, Lighthouse, React DevTools, throttling, breakpoints, source maps and heap snapshots.

**Workflow:** reproduce → isolate → observe → hypothesis → change one thing → verify → regression test.

**Scenarios:** stale API result, unexpected re-render, event-listener leak, slow request, layout shift, blocked main thread and broken Service Worker cache.

**Interview:** How do you debug a production-only issue? Find a memory leak? Prove a render is expensive? Inspect a failed network request?

**Challenge:** diagnose five seeded failures using DevTools and write the root cause for each.
